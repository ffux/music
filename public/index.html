Sign in securely using Terminal

On a computer with SSH access to your server, open Terminal and run:

ssh -t root@192.168.50.210 'python3 /root/music-alac-review/music/wrapper/login.py'

Enter your Apple ID, password and verification code only in Terminal. Inputs are hidden. Then return here and refresh the status.

If already signed in, the command keeps your current session. A phone needs an SSH client with existing server access; otherwise use your computer.
